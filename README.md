# Selectel Speedtest Widget для macOS

Фоновый агент + виджет, которые регулярно измеряют скорость интернета через
инфраструктуру [Selectel Speedtest](https://selectel.ru/speedtest/) и показывают
историю измерений в виде сетки 2×2 с мини-графиками: скачивание, загрузка, пинг, джиттер.

## Как это устроено

Проект состоит из двух частей:

| Часть | Роль |
|---|---|
| `SelectelSpeedtest.app` — агент в меню-баре (без иконки в Dock) | живёт в фоне, ведёт расписание, выполняет измерения, пишет историю и обновляет виджет |
| `SpeedtestWidget.appex` — виджет WidgetKit | только показывает данные: последнее измерение + спарклайны последних N измерений |

Виджет сам ничего не измеряет (WidgetKit не даёт фоновых таймеров) — он читает файл
истории, а агент после каждого измерения вызывает `WidgetCenter.reloadAllTimelines()`.

**Управление — только через агент.** Кликните на иконку в меню-баре (`↓138`, `⟳` во время
измерения, `⏸` на паузе):

- **Измерить сейчас** — запускает тест немедленно, не дожидаясь тишины в сети;
- **Стоп** — прервать идущее измерение;
- **Интервал** — как часто повторять: 15 минут … 12 часов (по умолчанию 1 час);
- **Пауза измерений** — полностью останавливает расписание (например, когда Mac подключён
  к телефону в режиме модема и трафик надо беречь; кнопка «Измерить сейчас» продолжает работать);
- **Запускать при входе** — автостарт агента (SMAppService).

Иконка виджета на рабочем столе/в центре уведомлений — только отображение: клик по виджету
открывает его в центре уведомлений, но кнопок управления в нём нет (ограничение WidgetKit).

## Правила запуска измерений

1. По расписанию тест стартует **только если в последние 5 минут сетевая активность была
   околонулевой** (< 1.5 Мбит/с — по системным счётчикам интерфейсов). Если сеть занята
   (видеозвонок, скачивание), агент просто ждёт: «Жду затишья в сети».
2. **Во время измерения** агент следит за «чужим» трафиком (общий минус трафик самого
   теста). Два подряд замера выше 6 Мбит/с — измерение останавливается с пометкой в меню.
3. **Нет сети** — повторная попытка через минуту.
4. Явное «Измерить сейчас» запускается всегда; отмена по активности при этом тоже действует.

Пороги и окно тишины настраиваются через `defaults write ru.rusjoan.selectel-speedtest`:

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `measurementIntervalMinutes` | 60 | интервал между измерениями |
| `quietActivityThresholdMbps` | 1.5 | порог «околонулевой» активности перед запуском |
| `quietWindowMinutes` | 5 | окно тишины перед запуском |
| `cancelActivityThresholdMbps` | 6 | «чужая» активность, при которой тест прерывается |
| `measurementsPaused` | 0 | пауза (тот же тумблер, что в меню) |

История (последние 48 измерений) хранится в JSON:
`~/Library/Containers/ru.rusjoan.selectel-speedtest.widget/Data/Library/SelectelSpeedtest/history.json`
— в контейнере расширения виджета: appex обязан быть сэндбоксированным и умеет читать
только свой контейнер, а несэндбоксированный агент спокойно пишет туда же.
App Group сознательно не используется — она требует registered capability App Groups
в provisioning-профиле (без неё ядро вырезает entitlement, и песочница блокирует чтение).

## Как работает измерение

Selectel Speedtest использует протокол LibreSpeed на `https://speedtest.selectel.ru`:

- **Пинг/джиттер** — 14 запросов `GET /empty.php` (первые два прогревочные);
  пинг — медиана, джиттер — среднее соседних отклонений;
- **Скачивание** — 4 параллельных потока `GET /garbage.php?ckSize=20` в течение 10 с
  (счётчик байтов из URLSession-делегата, потолок 500 МБ на тест);
- **Загрузка** — 4 параллельных потока `POST /empty.php` чанками по 4 МБ, 10 с;
- **IP** — `GET /getIP.php` (не критично, при ошибке просто пропускается).

## Сборка и установка

Требуются Xcode 16+ и [xcodegen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

```bash
xcodegen generate
xcodebuild -project SelectelSpeedtest.xcodeproj -scheme SelectelSpeedtest \
  -configuration Release -derivedDataPath .build build

APP=dist/SelectelSpeedtest.app
mkdir -p dist && rm -rf "$APP"
cp -R .build/Build/Products/Release/SelectelSpeedtest.app dist/

# запустить агента
open "$APP"
```

`project.yml` не задаёт `DEVELOPMENT_TEAM` — сборка по умолчанию подписывается ad-hoc
(`CODE_SIGN_IDENTITY: "-"`), для локального использования этого достаточно. Если хотите
автоматическую подпись своей командой разработки, впишите свой `DEVELOPMENT_TEAM` в
`project.yml` локально (не коммитьте его). App Group не используется, поэтому никаких
capabilities в портале не нужно.

Нюанс macOS Sequoia+: агент пишет файл истории в контейнер расширения виджета, и система
просит «доступ к данным других приложений». С ad-hoc подписью разрешение не запоминается
и запрос появляется при каждом запуске — после сборки переподпишите приложение своим
сертификатом (`scripts/sign-local.sh`), тогда достаточно разрешить один раз.

Важно: appex виджета **обязан** быть сэндбоксированным (`com.apple.security.app-sandbox`),
иначе `pluginkit` не регистрирует его и виджет не появится в панели. Доступ к файлу
истории у него — через entitlement App Group. Проверить регистрацию:

```bash
pluginkit -m -p com.apple.widgetkit-extension | grep selectel
```

Готовый бинарь после сборки лежит в `dist/SelectelSpeedtest.app` внутри проекта
(в `Contents/PlugIns/SpeedtestWidget.appex` — расширение виджета).

Или после `xcodegen generate` открыть `SelectelSpeedtest.xcodeproj` в Xcode и нажать ▶︎.
Сам `.xcodeproj` генерируется и не хранится в репозитории — источник правды `project.yml`.

Чтобы виджет появился в панели виджетов:

1. Запустите приложение хотя бы раз — агент начнёт работать, а расширение виджета
   зарегистрируется в системе (первая регистрация может занять до минуты);
2. ПКМ по рабочему столу → «Изменить виджеты…» (или центр уведомлений → «Изменить виджеты»)
   → найдите «Selectel Speedtest» → добавьте маленький или средний размер.

Рекомендуется перенести приложение в `/Applications` (особенно для автозапуска):

```bash
cp -R dist/SelectelSpeedtest.app /Applications/
```

## Структура проекта

```
project.yml                     # описание проекта для xcodegen
Sources/                        # цель агента
  AgentApp.swift                # @main, MenuBarExtra-окно (управление)
  MeasurementScheduler.swift    # расписание, тишина/пауза/отмена, обновление виджета
Widget/
  SpeedtestWidget.swift         # WidgetKit: timeline provider + виджет
Shared/                         # компилируется в обе цели
  SpeedtestEngine.swift         # LibreSpeed-протокол Selectel (ping/dl/ul)
  MeasurementStore.swift        # JSON-история в общем контейнере
  NetworkActivityMonitor.swift  # трафик по интерфейсам (sysctl NET_RT_IFLIST2) + сэмплер
  SpeedGrid.swift               # сетка 2×2 и спарклайны (общие для агента и виджета)
  SpeedtestModels.swift         # модель результата
```

## Известные ограничения

- Подпись ad-hoc (`-`): для локального использования этого достаточно; для распространения
  откройте проект в Xcode и укажите свою команду разработки (и при желании добавьте
  entitlement App Group `group.ru.rusjoan.selectel-speedtest` — код уже умеет его использовать).
- Виджет обновляется агентом после каждого измерения; если агент не запущен, виджет
  показывает последнюю сохранённую историю.
- Оценка «чужой» активности вычитает скорость теста из общего трафика — на очень «рваных»
  каналах возможны редкие ложные остановки; в этом случае запустите тест кнопкой повторно.
